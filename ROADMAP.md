# Roadmap

## 1.0 (October 2026)

The first public build.

- [x] Legacy brush and modern brush, switched with Legacy Mode
- [x] Pencil, eraser, paint bucket, eyedropper, line, rectangle, oval
- [x] Selection, Transform (with skew on Mac) and Lasso
- [x] Symbols and bitmaps, with a Library panel
- [x] Motion tweens with easing and a graph editor
- [x] Timeline right-click menus, frame blocks that can be moved or removed
- [x] Onion skin with range markers and tint settings
- [x] Audio track with waveform and scrubbing
- [x] Storyboard, animatic and storyboard sheet
- [x] Themes, including your own
- [x] Splash screen and credits
- [x] Home screen
- [x] Clipping masks and reference layers
- [x] iPad version: the same look and layout as the Mac, Apple Pencil, two-finger pan,
      pinch and twist, autosave, audio import, Preferences with themes
- [-] Plugins (the Cel on Film look): removed for 1.0
- [-] Sound effects for actions in the app: dropped, not needed
